# angusgee.dev

My studio site: fast, secure websites and practical AI integrations for small businesses.

**Live at [angusgee.dev](https://angusgee.dev)**

## How it's built

- Plain HTML and CSS. No framework, no build step, and one small script whose only job is showing prices in the visitor's currency.
- One stylesheet, one page, one accent colour.
- Plain static files, so it deploys anywhere in seconds and there is no server to maintain or attack.
- Built to load in under a second on a mobile connection.

## My approach

Most small-business websites ship megabytes of JavaScript to display text and pictures. This site is the counter-argument: semantic HTML, modern CSS and one small script for currency localisation. There is no admin panel to compromise, no plugins to patch and no build pipeline to break. That isn't nostalgia. It's what makes a site fast for visitors, cheap to host and a dead end for attackers.

Client work gets the same treatment. If you've arrived here from a proposal: yes, your site can be this fast too.

## Run it locally

Clone the repo and open `index.html` in a browser. That's it.
